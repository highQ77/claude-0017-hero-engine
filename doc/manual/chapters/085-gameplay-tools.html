遊戲邏輯小工具

幾乎每個遊戲都會用到的小工具：計時器、事件、可以重現的亂數、路徑曲線、物件池、存檔、記錄器，以及檢查用的除錯繪製。它們都不需要另外安裝外掛。

計時器

engine.timers：幾秒後做一件事、每隔幾秒做一件事。和瀏覽器的 setTimeout／setInterval 不同，它跟著遊戲的主迴圈走：遊戲暫停時不會觸發，預設也跟著時間縮放（慢動作時一起變慢，timeScale 為 0 時停住）。在 update 階段最前面觸發。

  • 腳本裡用 this.after(秒, 函式)、this.every(秒, 函式)：腳本結束（實體銷毀或移除腳本）時自動取消；要等待一段時間再往下執行用 await this.wait(秒)。
  • 回呼出錯時會記錄錯誤，其他計時器照常執行；畫面卡很久時，every 一幀最多補觸發 10 次。
  • 要在遊戲暫停時也持續（例如連線狀態）才用 setInterval。

可以重現的亂數

Random（@engine/math）：給同一個種子，每次得到同樣的一串數字。適合關卡產生、多人連線（大家用同一個種子就得到同樣的地圖）、可以重現的測試。不給種子時每次不同，但可以讀 rng.seed 記下來，之後重現同一局。

不適合密碼、抽獎等需要安全的用途。

路徑曲線

Path（@engine/math）：穿過幾個點的平滑曲線，用在巡邏路線、攝影機軌道、移動平台。t 從 0（起點）到 1（終點），依實際距離計算，所以用固定的速度推進 t 時移動速度是均勻的。

closed: true 時頭尾相連，t 超過 1 會繞回來。預設是轉彎自然、不會繞出多餘圈的曲線；給 tension（0~1）可以調整鬆緊。

物件池

子彈、火花、敵人這類一直建立又銷毀的東西，可以放進池子重複使用，避免遊戲中途建立物件時卡一下。池子不知道物件的內容：拿出來、放回去時要做的事寫在 onAcquire、onRelease。

存檔

createSave（@engine/core）：把進度存在瀏覽器裡（localStorage），下次打開還在。每個存檔記錄格式的版本號：遊戲改了存檔格式時把 version 加 1，讀到舊版本的存檔會交給 migrate 轉換。

  • 存檔壞掉、比遊戲還新、轉換失敗、validate 沒通過時，read 會丟出 SaveError，訊息說明是哪個存檔、什麼問題；list 照樣會列出壞掉的存檔，讓玩家可以刪除。
  • 存檔欄位名稱可以用英數字、中文、-、_；資料要能轉成 JSON。
  • 瀏覽器不允許使用 localStorage 時改存在記憶體裡（關掉頁面就沒了），並警告一次。測試或其他平台可以用 storage 自己提供（例如 memoryStorage()）。

除錯繪製

render.debug：在 3D 畫面上畫線、射線、方框、球、點、路徑，檢查 AI 的視線、射線、偵測範圍、路線。這些只是畫面上的線：不會被點選，也不會出現在場景檔裡。

  • 沒給 duration 只畫這一幀：每幀都要看到，就每幀呼叫（例如寫在系統裡）。
  • 預設畫在最上面（不會被擋住）；depthTest: true 時會被前面的物體擋住。
  • 物理的碰撞形狀另外有 physicsPlugin.debug = true（見物理）。
