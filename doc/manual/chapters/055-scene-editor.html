3D 場景編輯器

3D 場景編輯器是開發時使用的網頁工具，用來建立、編輯專案 public/scenes 裡的場景檔與 public/prefabs 裡的預製物件（新檔案存成 .xml；檔名寫 .json 就存成 JSON，舊的 JSON 檔照常可以開啟、編輯）。畫面用真正的引擎繪製，看到的和遊戲裡一樣。它只在 node hero dev 時提供，不會被打包到遊戲裡（場景檔本身在 public/，會照常發佈）。

開啟

工具列最左邊的 📁 選單可以切換要編輯的專案（projects/ 裡的資料夾，例如 official-demo-000-start、test）：開發伺服器會換成那個專案並重新啟動，頁面自動重新整理（有沒存的修改會先問）。這只影響這次執行的開發伺服器，開著的遊戲、UI 編輯器頁面也會一起換成新的專案；下次 node hero dev 仍然開 node hero select 選的專案。每個專案會各自記住上次開的場景檔。

畫面配置

  • 上方工具列（兩排）
    • 第一排（檔案與執行）：📁 切換專案、選擇場景檔、新增場景、重新讀取、目前的檔名（旁邊的 ● 代表有沒儲存的修改）⋯ 👁 預覽、▶ 試玩、儲存。
    • 第二排（編輯與顯示）：復原／重做、控制器模式（移動、旋轉、縮放）、世界／區域座標、對齊 ⋯ 「顯示」格線、碰撞體、UI 層，以及「編輯 UI ↗」。
    • 視窗太窄時，放不下的那一排可以左右捲動（不會把頁面撐寬）。
  • 左邊上方：階層：樹狀列出實體。「＋」加入物件（形狀、燈光、攝影機、空物件），⧉ 複製，✕ 刪除。預製物件的實例以 📦 和藍色名稱表示。
  • 左邊下方：素材：專案 public/ 裡的預製物件、模型（.glb、.gltf）、貼圖、音效。可以搜尋，↻ 重新讀取。
  • 中間：畫面：點物件選取。燈光、攝影機用小圖示表示，也可以點（環境光、半球光沒有位置，從階層選）。
  • 右邊：屬性：名稱、元件的欄位，「加入元件」加上其他元件。每個元件的 { } 按鈕切換成 JSON 編輯，✕ 移除元件。

操作

操作說明
左鍵拖曳／滾輪／右鍵拖曳轉動／拉近拉遠／平移編輯器的攝影機（不是場景裡的攝影機，不會存進檔案）
滑鼠移到階層的項目上畫面上那個物件出現藍色外框，上方顯示名稱、id 與元件（預製物件顯示檔案），方便找到物件在哪裡
拖曳控制器移動、旋轉、縮放選取的物件；放開時算一個復原步驟
數字欄位左右拖曳調整（按住 Shift 慢、Alt 快）、↑↓ 鍵加減，也可以輸入算式（例如 2*1.5）
階層拖曳拖到一列的上半／下半：排到它前面／後面；拖到中間：變成它的子物件；拖到空白處：移到最上層。換父物件時物件留在原地
雙擊階層／F2改名
Cmd/Ctrl／Shift＋點多選：在階層 Cmd/Ctrl 加選或取消、Shift 選一段；在畫面上兩個都是加選或取消。多選時控制器在最後選的物件上，一起移動、旋轉、縮放；複製、刪除也是一起（子物件跟著父物件，不會重複移動）

素材

  • 雙擊素材：打開預覽小視窗（可以拖曳標題列移動、拉右下角改大小；「⛶ 全畫面」或雙擊標題列放大到整個頁面，再按一次或 Esc 恢復；Esc 關閉）。圖檔顯示圖片與尺寸；模型（.gltf、.glb）可以旋轉、縮放，有動畫時可以選片段播放，並顯示頂點、三角形數與大小；預製物件（.xml、.json）與節點圖（.shader.json）可以直接編輯原始碼，按「儲存」或 ⌘/Ctrl+S 存回檔案（格式錯誤時不會寫入，下方會顯示錯在哪裡；存檔後畫面上的實例、用到節點圖的材質會跟著更新）；音效可以試聽。視窗下方的按鈕可以放進場景、套用到選取的物件，節點圖還可以在著色器編輯器打開。
  • 模型、預製物件：拖到畫面上，放在滑鼠下的位置（物件表面或地面）；預覽視窗的「放進場景」放在畫面中央。
  • 貼圖：拖到畫面上的物件，當作它材質的貼圖（map）；或先選物件，再按貼圖預覽視窗的「套用到選取的物件」。
  • 音效：拖到物件上，幫它加上音效（預設重複播放、載入後自動播放）；拖到空白處，新增一個音效物件。編輯時不出聲，試玩時才播放。
  • 模型的網址、動畫片段名稱在屬性面板有建議清單可以選。

特效與物理

  • 粒子：「＋」→「特效」有火焰、煙霧、火花。粒子在編輯時就會播放，改屬性馬上看到效果。壽命、大小等欄位有最小、最大兩個數字，一樣時是固定值；持續秒數空白或 ∞ 代表不停止。
  • 碰撞體：畫面上以藍色線框顯示（選取的物件比較亮），工具列「碰撞體」可以關掉。碰撞體標題的 ⤢「符合網格大小」依物件的網格或模型自動設定大小與位移。
  • 階層拖曳換父物件時，物件會留在原地：變換的數值自動換算成相對新父物件的值。

腳本

  • 「加入元件」→「腳本」，再從「＋ 加入腳本…」選專案 src/ 裡的腳本（class 名稱 extends Script）。一個物件可以掛好幾個腳本。
  • 腳本類別裡預設值是數字、文字、true／false 的公開欄位會變成參數欄位（例如 value = 1）；欄位上面的 /** 說明 */ 會顯示成提示。只存和預設值不同的參數。
  • 改了腳本的程式，切回編輯器分頁時清單會自動更新。
  • 遊戲裡要先用名稱登記腳本：scripts.register({ Coin })，載入場景時才會掛上（見〈腳本〉一章的「從場景檔掛腳本」）。

節點圖材質

  • 素材面板的「著色器」列出專案 public/shaders 裡的節點圖檔（著色器編輯器存的）。拖到畫面上的物件就套用成它的材質。
  • 網格的「材質」選「節點圖」後選檔案；「編輯 ↗」在著色器編輯器打開它。在著色器編輯器存檔後，畫面上的物件會自動更新；切回這個分頁時素材清單也會重新讀取。

場景設定

沒有選取物件時，屬性面板顯示整個場景的設定（存在場景檔的 settings，可以復原）：

  • 背景：預設（由遊戲程式決定）、顏色、透明。
  • 霧：線性（開始、最濃的距離）或指數（濃度）。
  • 後製特效：色調映射、曝光、光暈、暗角、調色、環境光遮蔽、底片顆粒、反鋸齒。只存改過的值；遊戲要安裝 PostProcessingPlugin 才有效果。
  • 尋路格子：AI 角色找路用（AIPlugin）。開啟後畫面上會顯示格子（紅色是擋住的）。「畫擋住的格子」後用左鍵在畫面上拖曳，按住 Shift 擦掉，一筆是一個復原步驟；「從碰撞體產生」把碰撞體佔的地方標成擋住（地板除外）；改範圍、格子大小時，已經畫的會保留在原本的位置。

UI 層（場景搭配的介面）

場景可以指定搭配的介面檔（public/ui 的 XML，存在場景檔的 ui）：它們會疊在 3D 畫面上，和遊戲裡看到的一樣，方便對照介面和場景的位置。

  • 設定：不選物件，在屬性面板的「介面（UI 層）」加入介面檔。第一個是底層，後面的依序疊上去（例如 ui/scene.xml 加上這個場景的 ui/forest/hud.xml）；↑ 調整順序，✕ 移除（不會刪檔案）。這只是預覽用，遊戲裡照常由程式載入介面。
  • UI 層（工具列，或按 U）：顯示／隱藏，瀏覽器會記住開關。UI 層只顯示、不能點，點擊會穿過去選取 3D 物件。
  • 編輯 UI ↗（工具列）：在另一個分頁用 UI 編輯器打開這個場景最上層的介面檔（屬性面板裡每個介面檔的「編輯」可以開其他的）。在 UI 編輯器的每個修改都會即時顯示在 3D 編輯器的 UI 層，不用存檔；存檔或還原後改回讀磁碟上的檔案。3D 介面面板（UIPanel3D）也會跟著更新。兩個編輯器要開在同一個瀏覽器；並排兩個視窗時可以邊改邊看。

預製物件

  • 存成預製物件：選一個物件，在屬性面板按「存成預製物件」。它連同子物件存到 public/prefabs/，場景裡換成實例（位置留在實例上）。之後要記得儲存場景。
  • 開啟：選實例按「開啟」編輯預製物件，儲存後按工具列的「← 回到…」返回，用到它的地方都會更新。檔案選單裡也可以直接選預製物件。
  • 解除連結：把實例換成預製物件的內容，變成一般物件，之後改預製物件不會再影響它。
  • 實例的屬性面板只顯示「覆蓋」的元件（通常是變換）；加入其他元件也會覆蓋預製物件根節點的同名元件。
  • 改預製物件裡面的東西：點畫面上預製物件裡的東西，第一次選到整個實例，再點一次選到裡面那個物件；在階層展開實例（📦 左邊的三角形）也可以選。改的屬性只影響這個實例（記在場景檔的 overrides），屬性面板以 ● 標出改過的元件，↺ 還原、「全部還原」清掉這個物件所有的修改。裡面的物件不能刪除或單獨複製。

預覽（和實際遊戲一樣）

按工具列的「👁 預覽」：在畫面區域裡執行真正的遊戲頁面，遊戲程式、介面、腳本、AI、自訂著色器都會跑，看到的就是玩家看到的畫面，而且直接進入正在編輯的場景。

  • 還沒存檔的修改也看得到：預覽中繼續在階層、屬性面板修改，遊戲裡的場景會即時重新載入（同一個瀏覽器，用 BroadcastChannel 傳送）。存檔或復原到原狀後，改回讀磁碟上的檔案。
  • 「↻ 重新開始」重新載入遊戲頁面；「新分頁 ↗」在新分頁全螢幕看（修改一樣會即時套用）；「✕ 關閉」或 Esc 回到編輯畫面。
  • 編輯預製物件時預覽開啟它的場景；直接從檔案選單開的預製物件，遊戲照常開始，用到它的場景會套用修改。
  • 遊戲要決定「預覽時從哪個場景開始」：場景用 load.sceneFile + create.sceneFromFile 建立，註冊後呼叫 previewScene()，預覽時回傳正在編輯的場景名稱，平常回傳 null（只在 node hero dev 作用）：

和「試玩」的差別：試玩只跑場景檔裡的內容（物理、粒子、音效），不執行遊戲程式；預覽跑的是完整的遊戲。

試玩

按「▶ 試玩」（Cmd/Ctrl+P）：畫面從場景裡優先度最高的攝影機看，物理開始運作（有剛體、碰撞體的物件會掉落、碰撞），音效開始播放，模型動畫、粒子照常播放。試玩中不能編輯；按「■ 停止」或 Esc 結束，所有物件回到試玩前的狀態。

試玩只跑場景檔裡的內容；遊戲程式（腳本、遊戲邏輯）不會執行，要看完整的遊戲請開遊戲頁面。

在遊戲裡使用

存好的場景檔用 load.sceneFile 載入，見場景一章的「場景檔」。完整的例子是範例專案 official-demo-000-start：public/scenes/orbit.xml、rain.xml 兩個場景共用舞台預製物件 prefabs/stage.xml，遊戲程式（src/levels.ts）載入後再依 id 加上腳本、自訂著色器材質與 AI 守衛。開發時遊戲和編輯器可以同時開著：在編輯器存檔，遊戲裡的場景會自動重新載入。自己定義的元件登記存讀規則後，就可以在屬性面板「加入元件」（沒有欄位說明的元件用 JSON 編輯）。
