腳本

腳本是替單一實體寫行為的類別（類似 Unity 的 MonoBehaviour）：繼承 Script，只寫需要的生命週期方法。適合「這個金幣被碰到要做什麼」這種跟著物件走的邏輯；要一次處理大量實體時用系統比較有效率。

生命週期

方法什麼時候呼叫
onAwake()加到實體上時立刻呼叫一次
onStart()第一次更新前呼叫一次
onUpdate(dt)每幀
onFixedUpdate(dt)固定步長（物理）
onLateUpdate(dt)每幀，所有 onUpdate 之後（攝影機跟隨）
onEnable()／onDisable()script.enabled 改變時
onDestroy()實體或腳本被銷毀時
onCollisionEnter(other)／onCollisionExit物理碰撞開始／結束（需要物理外掛）
onTriggerEnter(other)／onTriggerExit進入／離開感應區（sensor: true 的碰撞體）
onClick(hit)、onPointerEnter、onPointerExit滑鼠點擊、移入、移出這個物件（需要繪製與輸入外掛）

建構式執行時還沒有 entity，初始化請寫在 onAwake 或 onStart。腳本的錯誤不會讓遊戲當掉：會在主控台印出錯誤，其他腳本繼續執行。

腳本裡可以用的東西

寫法說明
this.entity、this.world、this.engine所屬實體、World、引擎
this.transform實體的 Transform
this.get(元件)、this.add(元件)、this.remove(元件)操作自己身上的元件
this.input、this.audio、this.physics、this.tweens、this.assets輸入、音效、物理、補間動畫、資源（對應的外掛要先安裝）
await this.wait(秒)、await this.nextFrame()、await this.waitUntil(條件)等待（受時間縮放與暫停影響）；腳本被銷毀時後面的程式不會執行
this.find(名稱)、this.sendMessage(實體, 方法, ...參數)用 Name 元件找實體、呼叫別的實體上腳本的方法
this.destroy()銷毀自己（或傳入其他實體）

範例：可以點擊的方塊

點擊方塊會彈跳一下並換顏色，滑鼠移上去時變亮；每個方塊每 1～3 秒會自己轉一圈。注意 Bouncer 的 speed 可以在 scripts.add 時用第三個參數設定。

腳本之間溝通

從場景檔掛腳本

在 3D 場景編輯器「加入元件」→「腳本」掛的腳本，存在場景檔的 ScriptList 元件裡。遊戲要用名稱登記腳本類別，載入場景時會自動掛上，參數覆蓋類別裡的預設值。腳本的 onStart 執行時，物件的其他元件都已經加好。

  • 沒有登記的腳本名稱會在主控台警告，並列出已登記的名稱。
  • 移除物件的 ScriptList 時，由它掛上的腳本也會一起移除。
  • 要先安裝 ScenePlugin 再安裝 ScriptPlugin，場景檔才讀得懂 ScriptList。
