API 參考

引擎所有公開的 API：每個模組一章，列出類別、函式、常數、介面與型別，以及它們的簽名、說明、參數、範例與原始碼位置。內容是開啟手冊時從引擎原始碼自動產生的，和程式碼永遠一致。

模組

怎麼讀

  • 引用：遊戲裡用 import { 名稱 } from '@engine/模組'；套件（packages/…）用 PluginManager 安裝。
  • 簽名：? 代表可以省略的參數或欄位，get 是唯讀屬性，static 是用類別名稱呼叫的。
  • 成員：類別的方法與屬性、介面的欄位、小工具分類（例如 create、spawn）裡的函式。成員很多時預設收合，點「成員」展開。
  • 範例：取自原始碼註解的 @example，可以複製、編輯；這些是程式片段，假設 world、scenes 等已經準備好（見〈開始使用〉的 engine.ts）。
  • 原始碼位置：標題右邊的 src/…:行號。
  • 找 API：上方的搜尋框輸入名稱，API 會列在最前面；其他章節內文裡的 API 名稱也會連到這裡。

同樣的內容也可以輸出成文字檔：node hero api（寫到 tips/api.txt）。
