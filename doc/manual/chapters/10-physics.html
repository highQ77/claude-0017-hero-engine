物理

物理外掛包裝了 Rapier 物理引擎：加上 RigidBody（剛體）的實體會受重力掉落、互相碰撞；Collider（碰撞體）決定形狀。物理在 fixedUpdate 以固定步長模擬，畫面會自動插值，不會抖動。

安裝

Rapier 是 WebAssembly，需要先非同步載入，所以用 await PhysicsPlugin.create()。需要先安裝 ecs 與 scene。

剛體與碰撞體

RigidBody 的 type說明
dynamic（預設）受重力與碰撞影響：箱子、球、被打飛的敵人
fixed完全不會動：地板、牆壁
kinematic由程式移動，會推開別人但自己不受影響：移動平台、玩家控制的角色

只有 Collider 沒有 RigidBody 的實體是固定的碰撞體（和 fixed 相同）。Collider 的常用欄位：

欄位說明
shapebox、sphere、capsule、cylinder、cone、convexHull、trimesh
halfExtents方塊的一半長寬高（預設 0.5，也就是 1×1×1 的方塊）
radius、halfHeight球、膠囊、圓柱的半徑與一半高度
restitution彈性（0 不彈，1 完全彈回）
friction、density摩擦力、密度（影響質量）
sensor感應區：不會擋住東西，只觸發進入／離開事件（收集物品、陷阱）

範例：掉落的方塊與球

點擊畫面上的物件把它往上打飛；每隔一段時間會掉下新的物件。

試試看：在 PhysicsPlugin.create() 加上 { debug: true } 看碰撞形狀，或改成 { gravity: { x: 0, y: -2, z: 0 } }。

常用方法

從 physicsPlugin.physics、資源 PhysicsKey 或腳本的 this.physics 取得：

方法說明
applyImpulse(實體, 力)瞬間推一下（跳躍、爆炸、被打飛）
applyTorqueImpulse(實體, 力)瞬間轉動
setLinearVelocity／getLinearVelocity設定、讀取速度
teleport(實體, 位置, 旋轉?)瞬間移動（不會穿過中間的東西產生碰撞）
raycast(起點, 方向, 最遠距離, { exclude })射線：回傳打到的實體、位置、法線；射擊、地面偵測
overlapSphere(中心, 半徑)找出範圍內的實體（爆炸範圍）
onCollision(回呼)所有碰撞事件：{ a, b, started, sensor }

只關心某個物件的碰撞時，用腳本的 onCollisionEnter(other)、onTriggerEnter(other) 比較方便（見「腳本」章節）。
