2D 介面

遊戲的選單、血條、背包等 2D 介面用 XML 描述，由 Yoga 排版引擎（和 React Native 相同的 Flexbox 排版）自動計算位置，再由引擎畫在 3D 畫面上方。介面會隨畫面寬度調整（RWD），手機、平板、電腦都能用同一份檔案。

排版

排版容器（<UI>、<UILayout>、視窗、分頁…）用 Flexbox 的規則排列子元件：

屬性說明
dir排列方向：v（上到下，預設）、h（左到右）
gap、padding、margin間距、內距、外距；padding="8 16" 是上下 8、左右 16
align和排列方向垂直的對齊：start、center、end、stretch
justify排列方向上的分布：start、center、end、between、around、evenly
flex="1"佔滿剩下的空間
width、height數字（像素）、百分比或 auto；搭配 minWidth、maxWidth
wrap="true"空間不夠時換行
position="absolute"脫離排版，用 left／top／right／bottom 定位（例如角落的按鈕）

版面尺寸

最外層的 <UI> 可以用 width、height 設定整個版面的大小：

寫法結果
<UI>沒寫：自動滿版（和 auto 相同）
<UI width="800" height="600">固定 800 × 600
<UI width="auto" height="auto">自動滿版，畫面尺寸改變時跟著改變
<UI width="auto" height="300">寬度滿版、高度固定 300
<UI width="50%">畫面寬度的一半；也可以加斷點，例如 md:width="600"
<UI width="100" height="fit">寬 100、高度依內容（fit：內容改變時自動跟著變）

只有 <UI> 的 auto 是「滿版」；其他元件的 auto 是依內容決定大小，但在預設的 align="stretch" 下會被父元件拉伸。fit 在任何元件上都是「依內容決定大小、不被拉伸」。版面放在畫面左上角，想置中時在外面再包一層，或用 left、top 調整。改改看下面的寬高：

樣式與外觀

重複的屬性寫成樣式，讓整份介面一致、修改時只改一個地方：

  • <UIStyle name="名稱" 屬性…/>：元件用 style="名稱" 套用（可以用空白隔開多個）。元件自己寫的屬性優先。
  • <UISkin for="UIButton" 屬性…/>：同一種元件的預設外觀，不用每個都寫 style。
  • <UIImport src="theme.xml"/>：匯入另一個檔案的樣式與外觀（整個遊戲共用一份主題）。

圖片背景與九宮格

任何元件都可以用 bgImage 加背景圖片。做框和按鈕時用 bgSlice（九宮格）：圖片切成九塊，四個角維持原樣，邊和中間延伸，怎麼縮放都不會變形。hoverBgImage、pressedBgImage 是滑鼠移入、按下時的圖片。

UI 編輯器裡有九宮格編輯器，可以直接在圖片上拖曳切割線。

在遊戲裡使用

用 UIPlugin 把介面疊在 3D 畫面上：點到介面的滑鼠事件不會傳給遊戲，透明的地方照常可以點到遊戲。XML 的 onClick="名稱" 會呼叫用 ui.setHandlers({ 名稱: 函式, … }) 註冊的同名函式（專案裡的 ui 從 engine.ts 引用）。uiPlugin.interactive = false 時介面只顯示、不攔截任何滑鼠或觸控，點擊全部穿透到遊戲（例如過場動畫、3D 場景編輯器的 UI 層）：

寫法說明
ui.get<UILabel>('id')用 id 取得元件（找不到是 undefined）；ui.require 找不到會報錯
label.setText('文字')改文字
el.set('屬性', 值)改任何屬性，例如 set('hidden', 'true')、set('background', '#f00')；給 null 回到原本的值
bar.value = 50進度條、滑桿等有 value 的元件可以直接設定
ui.setHandlers({ 名稱: 函式 })註冊事件處理函式（可以一次多個，隨時再加或換掉）
el.on('click', 函式)直接在元件上聽事件
ui.toast('文字', { icon, color, duration })顯示會自動淡出的提示（介面裡要有 <UIToast/>）

事件處理函式收到的參數有 target（觸發的元件）、value（滑桿、下拉選單的值）、checked（勾選框）、item／index（列表樣板的資料）。

列表資料

列表裡放一個 <UITemplate>，用 ui.setItems(列表id, 資料陣列) 依資料產生項目；樣板裡的 {欄位} 會換成資料的值，事件的 e.item 是被點到的那筆資料。

重複使用介面

常用的一小塊介面（卡片、金幣顯示）存成獨立的 XML 檔，用 <UIComponent src="檔名.xml"/> 放進來。外部檔案的 <UIStyle>、<UISkin> 只套用在它自己裡面；根元素 <UI> 的屬性也會套用，自己寫的屬性優先。

寬高只能寫在外部檔案的 <UI>：<UIComponent> 標籤上的 width、height 會被忽略（主控台會提醒）。

外部檔案的根元素嵌入後的大小
<UI>（沒寫寬高）依內容決定
<UI width="100" height="fit">寬 100、高依內容，例如 coin-badge.xml（單獨打開時也是依內容，不會滿版）
<UI width="300" height="120">固定 300 × 120
<UI width="auto" height="80">寬度填滿放置的位置、高度 80

畫面管理

遊戲通常有好幾個畫面：HUD、標題、設定、背包。UIScreenManager 管理多份 XML：show 換掉基本畫面，open 疊在上面（例如彈出視窗），back 關閉最上層。XML 裡可以直接寫 onClick="screen.open:settings"、onClick="screen.back"、onClick="screen.close"。

其他方法：screens.close(名稱)、screens.toggle(名稱)、screens.isOpen(名稱)、screens.closeAll()、screens.preload()（先載入所有畫面，打開時不用等）。

場景轉場與載入頁面

遊戲有好幾個場景（關卡）時，每個場景的介面放在 public/ui 底下自己的資料夾，資料夾名稱就是場景名稱，可以自訂。共用的檔案（主題、標題、設定）放在 public/ui 根目錄。在 UI 編輯器的檔案清單裡，它們會依資料夾分組列出。

場景資料夾裡的檔案用 ../ 引用上一層，例如 <UIImport src="../theme.xml"/>、bgImage="../pattern.svg"；同一個資料夾的圖片直接寫檔名。

SceneTransition 負責切換場景。每次進入場景（包括遊戲一開始進入第一個場景）都會：

  1. 畫面淡出成黑色（蓋住舊場景，也擋住滑鼠），移除舊場景的介面；
  2. 顯示這個場景的載入頁面，一邊下載資源（圖片、音效、模型、介面檔），一邊更新進度條；
  3. 載入完成後切換 3D 場景（SceneManager），在所有畫面的最下層疊上場景介面（hud），再淡入。

淡入前會等新畫面的圖片都讀完（ui.whenReady()，最多等 readyTimeout 秒），畫面不會一張一張跳出來。

用 UIPlugin 時，淡入淡出是一個蓋在整個畫面（含介面）上的單色面片，只改它的透明度，不會每幀重畫介面，高解析度螢幕也很順。移除舊介面、放上載入頁面、切換 3D 場景都在畫面全黑時完成，並多等幾幀讓重畫和著色器編譯做完才淡入。沒有 UIPlugin（例如獨立畫布）或指定 fader: null 時，改用介面圖層淡入淡出。

載入頁面是一般的 XML，用這些 id 顯示進度（都可以省略）：

id元件內容
loadingTitleUILabel場景名稱（title）
loadingBarUIProgressBar進度 0～100
loadingTextUILabel百分比
loadingItemUILabel剛載入的檔案名稱
loadingTipUILabel從 tips 隨機挑一則
