著色器編輯器

著色器編輯器是開發時使用的網頁工具，用節點拼出自訂著色器（不用寫程式）：貼在 3D 物件上的材質，或套用在整個畫面上的全螢幕效果（後製），存在專案 public/shaders 裡的節點圖檔（名稱.shader.json）。預覽用和遊戲一樣的引擎著色器庫繪製，看到的就是遊戲裡的樣子。它只在 node hero dev 時提供，不會被打包到遊戲裡（節點圖檔本身在 public/，會照常發佈）。編輯器移植自 Shader Composer。

開啟

執行 node hero dev 後打開 /shader-editor.html，或按任何一個編輯器頁首切換列的「著色器」（UI／3D 場景／著色器，會在另一個分頁打開）。網址加上 ?file=名稱 會直接開啟那個節點圖檔。

畫面配置

  • 工具列：第一排是檔案（開啟、新增、刪除、儲存 ⌘/Ctrl+S），檔名旁的圓點代表還沒儲存；第二排是範例、復原／重做、置中、匯入／匯出 JSON、清空。
  • 左邊：節點庫（可以搜尋，拖到節點圖或雙擊加入）與預覽（球體、立方體、圓環、平面 3D、平面 2D；拖曳旋轉、滾輪縮放，可以截圖、全螢幕）。
  • 中間：節點圖。每個節點都有即時縮圖，顯示那個節點輸出的結果。
  • 右邊：「屬性」編輯選取節點的參數與輸入；沒有選取時顯示在遊戲裡使用的程式。「程式碼」分頁是 three.js 從節點圖產生的著色器程式（WGSL；瀏覽器用 WebGL2 備援時是 GLSL）。

操作

  • 右鍵、空白鍵或雙擊空白處：新增節點選單。從連接埠拖曳連線到空白處，選好節點後會自動接上。
  • 從已連接的輸入拖曳會把連線拔起來；雙擊連線刪除。
  • 拖曳背景平移、滾輪縮放、F 全部置中；Shift＋點擊多選，Delete 刪除，⌘/Ctrl+D 複製，⌘/Ctrl+A 全選。
  • 把圖檔拖進節點圖會建立貼圖節點，拖到既有的貼圖節點上會替換圖片（縮到最長邊 1024px，存在節點圖檔裡）。

節點與型別

  • 分類：輸入（UV、時間、滑鼠、數值、顏色、參數、貼圖、法線、世界座標、物件座標、視線、光的方向）、數學、向量／UV、形狀與雜訊（圓、方形、棋盤、雜訊、FBM、3D FBM、Voronoi、雨滴）、光照（Lambert、Specular、Fresnel）、顏色（調色盤、HSV、亮度）、輸出。
  • 型別有 float、vec2、vec3、vec4，連線依型別上色。型別不同時自動轉換：float 擴展成向量，向量截取前幾個分量。數學節點的輸出維度取決於輸入中最大的那個。
  • Fragment Output：最後的顏色與透明度，可以選畫正面、兩面或背面，以及：
    • 光照：「不受光」時顏色就是最後的顏色（預設）；「標準」時建立在標準材質上，受場景的燈光、陰影影響，color 是基本色，emissive 是自己發的光（超過 1 的部分當成亮度倍數），另外可以設粗糙度、金屬度。
    • 透明：「自動」在 alpha 小於 1 或有連接時是半透明材質；「裁切」把 alpha 小於 0.5 的像素丟掉（溶解、鏤空），仍然是不透明材質。
    • 混合：「疊加」讓顏色加在後面的畫面上（發光、全像投影）。
  • Parameter／Color Parameter：可以在遊戲裡調整的數值、顏色。每個名稱變成一個 uniform：材質用 material.uniforms.名稱.value，全螢幕效果用 effect.uniforms.名稱.value 或後製設定的 uniforms。名稱相同的參數節點是同一個值；顏色是 THREE.Color（例如 .value.set('#ff0000')）。
  • Vertex Output（可以沒有）：頂點沿法線位移，加上位置偏移。接到它的節點在頂點著色器計算，所以雜訊、貼圖都能當高度圖。「法線：依位移重算」讓位移後的光照正確，建議搭配「平面 3D」預覽。
  • 世界座標與物件座標：用世界座標算的花紋，物件移動時會「流過」物件表面；要讓花紋固定在物件上，用 Object Position（物件座標，例如熔岩星球範例）。
  • 節點圖的顏色就是畫面上看到的顏色，不套用色調映射，遊戲裡和預覽一樣。

全螢幕效果（後製）

圖裡放 Effect Output（取代 Fragment Output）時，這張圖就是全螢幕效果：每個像素算出新的顏色，套用在整個畫面上。按「新增」時選「全螢幕效果」，或從範例的「全螢幕效果」群組開始。

  • Screen Color：畫面上這個位置原本的顏色。UV 可以偏移、切格子，做出扭曲、像素化、色差。只能用在全螢幕效果的圖。
  • Screen Size：畫面大小（像素），一個像素在 UV 上是 1 ÷ Screen Size。
  • Screen Blur：畫面模糊後的顏色（圓盤狀取樣，半徑是像素），做起霧、柔焦。
  • Rain Drops：玻璃上的雨滴，輸出水的高度、斜率（偏移畫面做出折射）、法線。
  • 顏色是畫面上看到的值：效果加在色調映射之後（display 階段），2D 介面不受影響。
  • 預覽固定是「平面 2D」，效果套用在一張示範畫面上；「程式碼」分頁顯示遊戲裡實際用的效果程式。
  • 3D 才有的節點（法線、世界座標、光照）在全螢幕效果裡是固定值，沒有意義。
  • 範例：暗角、復古（懷舊色調）、波動扭曲、CRT 掃描線；「內建全螢幕效果」群組有色差、像素化、調色＋暗角、雨落窗（和程式版的 EffectPresets、後製的調色一樣）。

在遊戲裡使用有兩種寫法，擇一即可：

寫法一：寫在後製設定（建議）。引擎會自動載入節點圖檔、建立效果、加進後製；開發時在著色器編輯器存檔，效果會立刻更新。場景檔的 "postfx": { "effects": [...] } 也可以這樣寫。

寫法二：自己建立。需要自己控制效果加入、移除的時機（例如按鈕開關），或要拿著效果物件改 uniform 時用。

範例

工具列「範例…」有 31 個範例，載入時會切換合適的預覽網格，可以用復原還原：2D 圖案（同心波紋、電漿、催眠螺旋、旋轉棋盤、霓虹光環、色相環、FBM 雲、Voronoi 細胞）、互動（滑鼠光暈）、3D 材質（Fresnel 邊緣光、卡通渲染、全息投影）、頂點位移（地形、水面波浪、熔岩星球、貼圖＋位移）、全螢幕效果（暗角、復古、波動扭曲、CRT 掃描線）、內建材質、內建全螢幕效果，以及空白的材質與全螢幕效果。

內建材質（溶解、全像投影、波浪、脈衝光環、條紋）和內建全螢幕效果（色差、像素化、調色＋暗角、雨落窗）是程式版 ShaderPresets、EffectPresets 與範例專案裡自訂著色器的節點圖版本，參數名稱也一樣（例如溶解的 progress）。存檔後就能用 loadShaderGraph、postfx.settings.effects 取代程式版；程式版照常可以用。

在場景裡使用

不用寫程式：在 3D 場景編輯器把素材面板「著色器」裡的節點圖拖到物件上，或在網格的「材質」選「節點圖」再選檔案（旁邊的「編輯 ↗」會在著色器編輯器打開它）。場景檔裡寫成：

  • 需要安裝 ShaderPlugin；節點圖載入前物件不會顯示。程式裡一樣可以寫 material: { shaderGraph: 'shaders/lava.shader.json' }。
  • 開發時在著色器編輯器存檔，開著的遊戲和 3D 場景編輯器會自動換成新的內容，不用重新整理。
  • 用到同一個節點圖檔的物件共用同一個材質（uniform 也共用）；要每個物件各自調整 uniform 時，改用下面的 loadShaderGraph。
  • 範例專案 official-demo-000-start 的月亮就是 shaders/lava.shader.json（熔岩星球範例，配合月亮的大小調過雜訊尺度與位移）。

在遊戲程式裡使用

用 loadShaderGraph 載入節點圖檔，轉成自訂著色器的定義（著色器名稱預設是檔名），再用著色器庫註冊、建立材質。材質的 uniform 可以在遊戲裡修改：uMouse（滑鼠，0~1）、uLightDir（光的方向）、uAspect（長寬比，平面 2D 用）；時間用引擎內建的 uTime。

  • 已經讀進來的內容用 shaderGraphDefinition(parseShaderGraphFile(文字), '名稱')；只想要 TSL 節點用 compileShaderGraph(graph)。
  • 也讀得懂 Shader Composer 匯出的 JSON：用「匯入 JSON」打開後儲存。
  • 自己的節點：defineShaderNode({ type, title, category, inputs, outputs, tsl })（tsl 函式拿到各輸入的節點、回傳各輸出的節點）（見 src/shaders/graph/nodes.ts 開頭的說明），編輯器和遊戲都要先執行這段程式。
