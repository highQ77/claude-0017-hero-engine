除錯工具：調整面板與效能監視器

開發時常常要「改一個數字、看看效果」。調整面板（lil-gui）讓你在遊戲執行中直接拖曳滑桿、勾選、選顏色，不用改程式再重新整理；效能監視器則顯示 FPS、每幀時間、CPU、GPU 與介面重畫的成本。兩者都是套件，用 PluginManager 安裝。

安裝調整面板

調整面板用 lil-gui 製作（已經是引擎的依賴，npm install 時會一起安裝）。安裝後按 I 顯示／隱藏：

內建的分類

有安裝對應外掛的分類才會出現：

分類需要的外掛可以調整
引擎—時間縮放（慢動作、快轉）、暫停、逐幀前進；顯示 FPS 與實體數量
繪製RenderPlugin背景顏色；顯示目前的 3D 解析度（動態解析度）
後製PostProcessingPlugin色調映射、曝光、反鋸齒、光暈（強度、範圍、門檻）、暗角
物理PhysicsPlugin重力、顯示碰撞形狀
音效AudioPlugin總音量、各群組音量（音樂、音效、介面、語音）、全部靜音

欄位會自動跟著遊戲裡的數值更新（例如在選單切換了反鋸齒，面板上的選項也會變）。

加自己的參數

從 InspectorKey 取得面板，folder(名稱) 建立自己的分類，再用 lil-gui 的寫法加欄位。gui 就是 lil-gui 本身，完整用法見 lil-gui 說明：

寫法欄位
f.add(物件, '屬性', 最小, 最大, 間隔)數字滑桿
f.add(物件, '屬性')依值的型別：數字欄、勾選框（布林）、文字欄；值是函式時是按鈕
f.add(物件, '屬性', ['a', 'b'])、f.add(物件, '屬性', { 名稱: 值 })下拉選單
f.addColor(物件, '屬性')顏色（'#ff0000'、數字 0xff0000 或 THREE.Color）
.name('中文名稱')、.listen()、.onChange(fn)、.disable()顯示名稱、自動更新、改變時呼叫、唯讀

程式控制

調整面板是蓋在遊戲上的 HTML：點面板不會傳給遊戲（也不會被 2D 介面攔截），在數字欄裡打字時也不會觸發遊戲的按鍵。它是開發工具，正式發佈時可以不安裝，或用 visible: false 預設隱藏。

效能監視器

效能監視器畫在引擎的 2D 介面上（不是 HTML），按 ` 顯示／隱藏。面板可以用滑鼠（或手指）拖到畫面任何地方，位置會記住（存在瀏覽器裡，重新整理後還在）：

欄位怎麼看
曲線每一幀的時間：綠色正常（≤ 17.5 ms）、橘色稍慢（≤ 34 ms）、紅色卡頓（> 34 ms）
每幀平均每幀時間與最快～最慢
CPU、階段引擎各更新階段的時間（輸入、物理、更新、繪製…），找出哪個系統太慢
解析度3D 場景的解析度；畫面跟不上時動態解析度會降低它（介面不受影響）
GPU、資源每幀的繪製呼叫、三角形數量；幾何、貼圖、著色器數量（一直增加代表沒有釋放）
介面2D 介面每秒重畫幾次、平均與最久的時間。介面重畫不在引擎的階段裡：卡頓卻看不到 CPU 時間時看這一行
