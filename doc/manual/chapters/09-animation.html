補間動畫

補間動畫（Tween）讓數值在一段時間內平滑地變到目標值：物件移動、縮放彈跳、介面淡入、數字跳動都用得到。AnimationPlugin 另外提供模型骨架動畫（Animator）與動畫狀態機。

基本用法

安裝 AnimationPlugin 後，從 animationPlugin.tweens、資源 TweensKey 或腳本的 this.tweens 取得補間管理器：

緩動曲線

同樣從左到右移動，不同的緩動曲線給人完全不同的感覺。按執行比較看看：

可以用的名稱：linear、quadIn／quadOut／quadInOut、cubicIn／cubicOut／cubicInOut、sineIn／sineOut／sineInOut、expoIn／expoOut、backIn／backOut／backInOut、elasticOut、bounceIn／bounceOut；也可以傳入自己的函式 (t) => t * t。

時間軸

好幾段動畫依序（或同時）播放時用時間軸：每一步預設接在前一步後面，at: '<' 和前一步同時開始，at: 秒數 指定絕對時間。

模型動畫

載入的 glTF 模型若有動畫，加上 Animator 元件後用 play.animation(world.require(實體, Animator), '動畫名稱', { loop: true }) 播放；動作很多時用 AnimationStateMachine 定義狀態與轉換條件（例如走路 → 跑步），在程式裡用 play.trigger(狀態機, '觸發名稱') 觸發。

沒有模型檔時，也可以自己組物件、用資料寫動畫片段：create.mesh 的 name 是軌道裡的物件名稱，create.clip 的鍵是「名稱.屬性」（position、scale、rotation、visible、材質的數字或顏色）。
