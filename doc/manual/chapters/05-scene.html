場景、位置與父子關係

ScenePlugin 提供三件事：Transform（位置、旋轉、縮放）、父子關係（子物件跟著父物件移動），以及場景的載入與切換。

Transform

任何要出現在 3D 空間裡的實體都需要 Transform。它的欄位是 three.js 的數學物件，可以直接使用 three.js 的方法：

欄位類型說明
positionVector3位置（相對父物件）
rotationQuaternion旋轉（四元數，不會有萬向鎖問題）
scaleVector3縮放
worldMatrixMatrix4世界矩陣（引擎計算，唯讀）

父子關係

建立時給 parent（spawn.entity、spawn.mesh、spawn.light、spawn.camera 都可以）：子物件的 position 變成相對於父物件，父物件移動、旋轉、縮放時子物件跟著動；父物件被銷毀時子物件也會一起銷毀。建立之後才要改父物件，用 hierarchy.setParent(子, 父)（null 代表脫離）。下面是一個小太陽系：月球是地球的子物件，地球是太陽的子物件。

場景管理

場景是一個有 name 與 setup(world) 的物件。setup 期間建立的實體屬於這個場景，切換場景時會自動銷毀。

方法說明
scenes.register(...場景)登記場景
scenes.load(名稱)卸載目前的場景、載入新場景
scenes.load(名稱, { additive: true })疊加載入（不卸載現有場景），例如暫停選單
scenes.unload(名稱)卸載一個場景
scenes.persist(實體)讓實體不隨場景卸載（例如玩家、背景音樂）

場景檔

場景也可以寫成場景檔，放在專案的 public/scenes/。檔案記錄實體、名稱、父子關係與元件資料，可以寫成 XML（3D 場景編輯器 /s3d-editor.html 預設存成 XML）或 JSON，兩種內容完全一樣，載入時自動判斷。先看 JSON 的寫法：

  • id：檔案裡的編號，parent 用它指定父節點；name 是實體名稱（Name 元件），可以用 scripts.find('樹') 找到。
  • 角度一律用「度」：Transform 的 rotation（X、Y、Z 順序）、Light 的 angle。省略的欄位用預設值。
  • 能存的元件：Transform（場景外掛）、MeshRenderer、Camera、Light（繪製外掛）、Model（資源外掛）、Animator（動畫外掛）、RigidBody、Collider（物理外掛）、ParticleEmitter（粒子外掛）、AudioSource（音效外掛，playing: true 代表載入後自動播放）、Text3D（3D 文字外掛）、UIPanel3D（3D 介面外掛；事件處理函式要用 ui3d.setHandlers 註冊）。粒子的 lifetime、size 等可以寫數字或 [最小, 最大]，角度欄位一樣用度。網格的幾何、材質要寫描述；程式建立的 three.js 物件不能存。外掛要裝在 ScenePlugin 之後，才會登記自己的元件。
  • 檔案裡有沒登記的元件（例如沒裝那個外掛）只會警告並略過；格式錯誤會說明是哪個實體、哪個欄位。
  • ui（可省略）：這個場景搭配的介面檔，例如 ["ui/scene.xml", "ui/forest/hud.xml"]。3D 場景編輯器會把它們疊在畫面上預覽；遊戲不會自動載入，照常用 UIScreenManager、SceneTransition 或 ui.load 載入介面。

XML 寫法

同一個場景寫成 XML：子實體直接寫在父實體裡面（不用 parent），元件的標籤就是元件名稱，欄位寫成屬性。

  • 屬性值：true／false 是布林，像數字的是數字，用空白隔開的多個數字是陣列（position="2 0 -1"），其他都是文字。
  • 物件寫成子元素（<geometry cone="…"/>）；其他少見的值：is="null"（例如 <play is="null"/>）、is="array"（裡面放 <item …/>）、看起來像數字的文字 <text is="string" value="12"/>。不能當標籤的鍵（中文、有 / 的）寫成 <_ key="鍵" …/>。
  • <Settings> 是場景設定，<SceneUI src="…"/> 是搭配的介面檔（JSON 的 ui）；預製物件的實例寫成 <Entity id="tree1" prefab="prefabs/tree.xml">，覆蓋裡面的東西用 <Override target="leaf" name="…">元件…</Override>（<Collider is="null"/> 代表移除）。
  • 可以寫註解 <!-- … -->，但用編輯器存檔時會重新產生檔案（註解不會保留）。格式錯誤時訊息會附上行號。

開發時自動重新載入

用 load.sceneFile 載入、create.sceneFromFile 建立的場景，在 node hero dev 時會自動重新載入：場景檔（或它用到的預製物件）存檔後，開著的遊戲馬上換成新的內容，不用重新整理頁面。在 3D 場景編輯器存檔、或直接修改檔案都可以。

  • 重新載入會重新執行場景的 setup（場景裡的實體重建，persist() 的實體不受影響）。
  • 不想要時：create.sceneFromFile('forest', data, { hotReload: false })。打包後的遊戲不包含這個功能。

預製物件

常用的一組物件（例如一棵樹、一個箱子）可以存成預製物件，放在 public/prefabs/，格式和場景檔一樣，但要剛好有一個最上層的實體。場景裡用 prefab 放置：

  • 載入時展開：預製物件的根節點變成 tree1，裡面其他的實體是 tree1/原本的 id（例如 spawned.entities.get('tree1/leaf')）。
  • 實例的 name、parent 取代根節點的；實例的 components 逐一覆蓋根節點的同名元件（通常只有位置）。
  • 修改預製物件檔，所有用到它的場景都會跟著變。預製物件裡也可以再放預製物件（不能互相包含）。
  • load.sceneFile 會自動下載用到的預製物件；自己組資料時，把內容放在 prefabs（路徑 → 預製物件檔）。
  • 要改預製物件裡面的東西（只影響這個實例）用 overrides：鍵是預製物件裡的 id（巢狀時是 a/leaf），components 裡的元件整個取代原本的，null 代表移除。預製物件改過、對不到的覆蓋只會警告。

場景設定

不屬於任何實體的設定寫在 settings，載入場景時套用、卸載（切換場景）時恢復原狀。每個鍵由對應的外掛處理，沒有安裝那個外掛時只會警告：

鍵寫法外掛
background"#223344"，或 null（透明）RenderPlugin
fog{ "color", "near", "far" }（線性）或 { "color", "density" }（指數）RenderPlugin
postfx和 PostFxSettings 一樣，只寫要改的，例如 { "bloom": { "enabled": true } }PostProcessingPlugin
navGrid{ "min": [x, z], "max": [x, z], "cellSize", "y", "walkable": [可走, 擋住, 可走…] }AIPlugin

navGrid 的 walkable 是「可走、擋住」交替的格數（一列一列，從最小角開始），省略代表全部可走；程式裡可以用 navGridToFile、navGridFromFile（@engine/ai）轉換。自己的外掛也可以登記設定：scenePlugin.codecs.registerSetting({ key, apply(value, ctx) { …; return 恢復的函式 } })。

程式裡也可以直接讀寫：sceneFile.spawn(world, 資料) 建立實體，sceneFile.write(world, 實體清單) 存成場景檔，sceneFile.stringify(資料) 轉成 JSON 文字，sceneFile.stringifyXml(資料) 轉成 XML 文字；sceneFile.parse(文字) 兩種都能讀。
