專案的資料夾

引用引擎

遊戲程式用 @engine/模組 引用引擎，例如 import { Engine } from '@engine/core'；也可以用總入口 import * as hero from '@engine'（所有模組都在 hero 底下，打包時只包含用到的部分）。向量、四元數、顏色從 @engine/math 引用（import { Vector3, Quaternion } from '@engine/math'，就是 three.js 的類別）；常用的攝影機、燈光、網格、材質、貼圖不用 three.js 也能建立（見繪製的「簡潔的寫法」）。

engine.ts：外掛設定

node hero create 產生的專案把引擎和外掛放在 src/engine.ts，遊戲程式（main.ts 和其他檔案）從那裡引用：

  • 一行一個外掛，照順序安裝：有相依的在後面（例如介面要在繪製之後、輸入放最後），不要調換順序。
  • 預設開啟常用的：ECS、場景、繪製、資源、動畫、粒子、音效、腳本、AI、2D 介面、輸入。
  • 預設關閉、需要時取消註解（連同上面的 import）：著色器、後製（裝了之後畫面會套用色調映射，色調會和沒裝時不同）、3D 文字、物理（多下載約 2 MB）、3D 介面。註解掉的外掛不會安裝，打包時也不會包含。
  • 哪裡改設定：建立時就決定的（陰影、反鋸齒、物理的初始設定…）改 engine.ts；執行中可以改的（背景顏色、後製效果、音量、介面的事件處理…）在 main.ts 改，例如 render.scene.background = new Color('#203040')、ui.setHandlers({ start: … })、ui3d.setHandlers({ buy: … })。
  • 匯出的名稱：外掛叫 xxxPlugin（很少直接用），常用的物件用短名稱：world（遊戲世界）、ui（介面）、audio（音效）、scenes（場景管理）、hierarchy（父子關係）、input（輸入）、physics（物理）、tweens（補間）、assets（資源）、scripts（腳本）；外掛本身就是常用 API 的直接用短名稱：ecs、render、postfx、ai、ui3d。遊戲程式（包括系統裡）直接引用它們，例如 import { audio } from './engine'，就能 audio.play('sounds/jump.wav')。

手冊範例的 engine.ts

手冊的範例和遊戲專案的 main.ts 一樣，用 import { engine, world, ui, … } from './engine' 取用引擎和外掛，不用自己建立：手冊已經準備好一份 engine.ts（doc/manual/engine.ts），每次按「執行」都會重新建立，範例之間不會互相影響。範例可以直接複製到專案的 main.ts。

它把所有外掛都裝上（多人連線、小地圖除外），匯出的名稱和專案的 engine.ts 一樣：

名稱是什麼
engine、world引擎、遊戲世界
ecs系統：ecs.each(…)、ecs.addSystem(…)
scenes、hierarchy場景管理、父子關係
render繪製（render.scene、render.pick(…)）；背景色 0x15181f、陰影開啟
postfx後製特效；色調映射預設不使用（畫面和沒裝時一樣），要光暈寫 postfx.settings.bloom.enabled = true
assets、tweens、audio資源、補間、音效
physics、physicsPlugin物理世界；physicsPlugin.debug = true 顯示碰撞形狀
scripts、ai腳本、AI（行為樹、尋路）
shaders著色器庫
ui、ui3d2D 介面（沒有預先載入介面檔，範例用 ui.loadString(…)）、3D 介面面板
input輸入

另外 3D 文字、粒子也都已經安裝（Text3D、ParticleEmitter 元件直接用）。攝影機繞轉控制預設開啟：可以用滑鼠拖曳轉動畫面。

程式的基本步驟

  1. 建立外掛（專案裡在 engine.ts）：new EcsPlugin()、new RenderPlugin()…（需要非同步初始化的用 await XxxPlugin.create()，例如介面和物理）。
  2. 安裝到引擎：engine.use(外掛)。有依賴關係的外掛要照順序安裝（例如繪製需要先有 ecs、scene），順序錯了會有錯誤訊息提醒。
  3. 建立實體：world.spawn(元件…)（位置用 Transform.at(x, y, z)）；攝影機、燈光、網格、任意實體可以用 spawn.camera、spawn.defaultLights、spawn.mesh、spawn.entity 一行建立，可以一起指定位置、父節點（parent）、名稱（name），回傳建立的實體。
  4. 寫遊戲邏輯：系統或腳本（Script 類別）。最常見的「每幀對某些實體做事」用 ecs.each('名稱', [元件…], (實體, 元件資料…, time) => …)；需要先準備資料、或要 init／dispose 的用 ecs.addSystem（見 ECS）。
  5. 開始：engine.start()。
