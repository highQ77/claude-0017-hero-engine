音效編輯器

音效編輯器是開發時使用的網頁工具，用 Tone.js 合成遊戲音效（金幣、跳躍、雷射、爆炸…），不用錄音、也不用找素材。每個音效存成兩個檔案：public/sounds/名稱.sfx.json（合成參數，可以再打開修改）與 名稱.wav（烘焙好的聲音）。遊戲播放的是 .wav，所以遊戲不需要 Tone.js，和一般音檔一樣使用。它只在 node hero dev 時提供。

開啟

執行 node hero dev 後打開 /se-editor.html，或按任何一個編輯器頁首切換列的「音效」。網址加上 ?file=名稱 會直接開啟那個音效。在 3D 場景編輯器的素材面板雙擊音效編輯器做的 .wav，預覽視窗會有「在音效編輯器打開」。

畫面配置

  • 工具列：第一排是檔案（開啟、新增、刪除、下載 .wav、儲存 ⌘/Ctrl+S）；第二排是復原／重做、播放（空白鍵）、自動播放、隨機產生、微調變化（幅度：小／中／大）。
  • 左邊：20 個範本（金幣、跳躍、雷射、爆炸、升級、受傷、點擊、選單移動、拾取、傳送、射擊、打擊、腳步、揮動、鈴聲、水滴、錯誤、成功、落地、警報；每次點都有一點不同）與圖層清單（最多 4 層，勾選框可以暫時關掉一層）。
  • 中間：波形（點一下播放）、選取圖層的音量包絡、音高與濾波曲線。曲線上的圓點可以直接拖曳。
  • 右邊：「圖層」是選取圖層的參數，「整體」是整個音效的效果。滑桿旁邊的數字也可以直接輸入。

音效怎麼組成

  • 圖層：一個音效由 1～4 層疊起來。每一層的聲音來源可以是振盪器（方波、鋸齒波、三角波、正弦波）、雜訊（白、粉紅、棕）或 FM 合成（金屬聲、鈴聲）。
  • 音高：起始與結束音高不同時會滑音（往上是跳躍、升級，往下是受傷、雷射）；顫音的速度與深度（100 音分 = 半音）。
  • 濾波：低通、高通、帶通，起始與結束頻率不同時會掃頻（爆炸聲從亮變悶）。
  • 音量包絡：延遲開始、起音、衰減、延音音量、延音維持、釋音。用「延遲開始」可以做出兩段的音（例如金幣的「叮—咚」）。
  • 整體：失真、位元數（越小越粗糙、越復古）、回音、殘響、整體音量，以及「自動音量」（把最大音量調到接近滿格，不同音效的音量比較一致）。

每次修改都會重新合成，聽到的就是會存成 .wav 的那份聲音（拖曳滑桿、圓點時，放開才自動播放）。

在遊戲裡使用

和一般音檔一樣：場景檔的 AudioSource 寫 sounds/coin.wav，或在程式裡播放：

  • 修改音效後再存檔，.wav 會跟著更新；用到它的地方不用改。
  • 名稱和 public/sounds 裡現有、但不是用音效編輯器做的 .wav 相同時，存檔前會先問要不要覆蓋。
  • 刪除音效會同時刪除 .sfx.json 與 .wav。
