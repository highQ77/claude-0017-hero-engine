輸入：鍵盤、滑鼠、觸控、手把

InputPlugin 把瀏覽器的事件整理成每一幀的狀態：哪些鍵按住、這一幀剛按下、剛放開。建議用「動作」（跳躍、移動）來寫遊戲，同一個動作可以對應鍵盤、手把等多種按鍵。

按鍵狀態

遊戲程式從專案的 engine.ts 引用輸入：import { input } from './engine'（就是 inputPlugin.input；腳本裡是 this.input）。

寫法說明
input.keyboard.isDown('KeyW')按住中（每一幀都是 true）
input.keyboard.wasPressed('Space')這一幀剛按下（只有一幀是 true）
input.keyboard.wasReleased('Space')這一幀剛放開
input.mouse.isDown('Left')滑鼠按鍵：Left、Middle、Right
input.pointer指標位置：x、y（像素）、ndcX、ndcY（-1～1，點選物件用）、deltaX、deltaY（這一幀的移動量）、wheel
input.gamepad第一支手把（沒有接手把時是 undefined）

鍵盤用 KeyboardEvent.code 的名稱，和鍵盤配置無關：KeyA～KeyZ、Digit0～Digit9、Space、Enter、Escape、ShiftLeft、ArrowUp…

動作對應

在 input.actions 定義動作，遊戲程式只問「跳躍有沒有按」，不用管是哪個鍵：

  • bind(動作, [按鍵…])：按鍵動作，用 isDown／wasPressed／wasReleased 查詢。
  • bindAxis(動作, { negative, positive, padAxis })：軸動作，axis(動作) 回傳 -1～1。
  • 綁定字串：鍵盤 'KeyW'、滑鼠 'Mouse:Left'、手把 'Pad:A'（任一手把）或 'Pad0:A'（第 0 支）。

先點一下畫面（讓預覽框取得鍵盤焦點），再用 WASD 或方向鍵移動、空白鍵 跳躍。有手把的話也可以用左搖桿和 A 鍵。

暫停時主迴圈（包含輸入外掛）不會執行。像「按 P 暫停／繼續」這種在暫停中也要有反應的按鍵，請直接聽瀏覽器的 keydown 事件。
