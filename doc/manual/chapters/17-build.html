打包發佈與常見問題

把遊戲打包成靜態網站，放到網頁伺服器（GitHub Pages、Netlify、自己的主機）就能玩；也可以包成 macOS App，雙擊就能玩。

打包

打包時：

  • 只會打包遊戲頁面，UI 編輯器等開發工具不會包含在內。
  • public/ui 的 XML 會轉成 JS 模組，載入時不用再抓 .xml 檔。
  • 物理引擎（Rapier）、字型等用動態載入：沒用到的功能不會下載。

macOS App（Tauri）

node hero build --mac 用 Tauri 把網頁版包成 macOS App：一個視窗、裡面就是遊戲，不需要瀏覽器，也不用架伺服器。App 用系統內建的網頁引擎（WebKit），檔案很小（約 10 MB 左右）。

  • 需要：macOS、Rust（brew install rust 或 rustup）、Xcode Command Line Tools（xcode-select --install）。Tauri 的指令工具已經在 npm install 時安裝。
  • 第一次比較久：要下載、編譯 Rust 套件（幾分鐘）；之後只重新包裝，很快。編譯結果放在引擎目錄的 .tauri/（不用管它，刪掉也沒關係，下次會重建）。
  • 視窗：標題用專案 index.html 的 <title>，大小 1280 × 720（可以縮放）。
  • 圖示：在專案資料夾放 icon.png（建議 1024 × 1024、正方形）就會用它；沒有時用引擎預設的圖示。
  • App 的識別碼是 com.heroengine.專案名稱。沒有簽章：別人的電腦第一次打開時，要在 Finder 裡按右鍵 →「打開」。
  • Windows、iOS、Android 還不支援（--windows 等參數會提示）。

引擎的模組結構

引擎分成分層的模組，下層不知道上層的存在，打包時只包含用到的部分（分模組引用或用總入口 hero.* 都一樣）：

  • 資源鍵放在各模組的 keys.ts：例如腳本的 this.physics 只需要 physics/keys.ts，不會把整個物理模組打包進來。
  • 同一層要合作時透過下層的介面：例如物理要用網格的形狀建立碰撞體，由繪製外掛提供 MeshGeometryKey（定義在 scene），物理不直接依賴繪製。
  • 套件管理不會帶進整個引擎：new PluginManager(engine, { api: { ui2d } }) 只把給的模組交給套件；要全部時用 { api: engineApi }。
  • package.json 的 sideEffects 宣告 src/ 沒有「引用時就執行」的程式，打包工具才能去掉沒用到的模組。模組最上層不要寫會改動外部狀態的程式（註冊、改全域變數），要做的話放在外掛的 install() 裡。

這些規則由測試自動檢查（node hero build 會執行）：tests/module-deps.test.ts 檢查每個模組只引用允許的模組、沒有循環；tests/tree-shaking.test.ts 打包幾個最小的遊戲，檢查沒有多包含不相干的模組。新增模組時要在 module-deps.test.ts 的 RULES 寫好它可以依賴哪些模組。

使用手冊本身

打包結果用相對路徑，可以放在網站的任何路徑，也可以不用伺服器、直接雙擊 dist/doc/index.html（file://）閱讀。

新增章節：在 doc/manual/chapters/ 加一個 HTML 檔（檔名開頭的數字決定順序），範例寫在 <script type="text/plain" class="example" data-lang="ts"> 裡。詳細說明見 doc/README.md。

常見問題

畫面一片黑，什麼都沒有

  • 有沒有攝影機？攝影機有沒有 Transform、有沒有朝向物件（spawn.camera 的 target，或 math.lookAt）？
  • 有沒有燈光？MeshStandardMaterial 沒有燈光是黑色的（可以先用 MeshBasicMaterial 測試）。
  • 物件有沒有 Transform？沒有 Transform 的網格不會顯示。
  • 有沒有呼叫 engine.start()？

安裝外掛時出現「需要先安裝」

外掛有依賴順序，例如 RenderPlugin 需要 ecs 與 scene、AudioPlugin 需要 assets、UIPlugin 需要 render。照錯誤訊息把需要的外掛先 use。

背景音樂沒有聲音

瀏覽器要求使用者先點擊或按鍵才能播放聲音。音效外掛會在第一次互動後自動開始播放。

按鍵沒有反應

  • 遊戲暫停時輸入外掛不會更新；暫停鍵請直接聽 window 的 keydown。
  • 焦點在輸入框裡時，輸入外掛不會攔截按鍵。
  • 在這本手冊的預覽框裡，要先點一下畫面才能接收鍵盤。

介面的按鈕點不到遊戲物件

這是刻意的：點到介面的事件不會傳給遊戲。透明、沒有背景的地方會穿透；想讓某個有背景的元件也穿透，加上 pointerEvents="none"。

在 Safari 上拖曳或點擊不正常

介面用 Pointer Events 處理滑鼠和觸控。自己加的 HTML 元素若蓋在畫布上，請確認沒有攔截 pointerup；拖曳時離開視窗、觸控被系統取消時，介面會自動中斷拖曳。
