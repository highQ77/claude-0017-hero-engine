UI 編輯器

UI 編輯器是開發時使用的網頁工具，用來建立、編輯專案 public/ui 裡的介面檔。它只在 node hero dev 時提供，不會被打包到遊戲裡。

畫面配置

區域用途
XML 管理器（左側）列出 public/ui 的介面檔，依資料夾分組（「共用」與每個場景）：新增、重新命名、刪除、切換。＋ 場景 建立場景資料夾，裡面放好 hud.xml 與 loading.xml；重新命名檔案時寫成「資料夾/檔名.xml」可以移到別的場景
結構樹介面的元件階層；可以拖曳調整順序、放進其他容器
預覽（中間）即時排版結果；點元件可以選取，上方可以切換手機／平板／桌機寬度
原始碼按「打開原始碼」開啟浮動視窗（拖曳標題列移動、拉邊緣調整大小、雙擊全螢幕），直接編輯 XML；打字時會依 a～z 列出標籤的屬性提示與說明
屬性面板（右側）選取元件的屬性；顏色、圖片、九宮格都有專用的編輯器
元件庫（右側）點一下加入元件；滑鼠移上去看說明，按右邊的預覽鈕彈出視窗看實際運作的樣子
資源管理器列出 public/ui 裡的圖片，可以拖到背景圖片欄位
紀錄面板（下方）錯誤訊息、存檔紀錄

常用流程

  1. 在 XML 管理器新增一個檔案，例如 shop.xml。
  2. 從元件庫加入版面（垂直排版、視窗），再放入按鈕、文字、列表。
  3. 在屬性面板調整間距、顏色；常用的組合存成 <UIStyle>，或放到共用的 theme.xml 用 <UIImport> 匯入。
  4. 切換預覽寬度檢查手機版排版，需要時加上 md: 等斷點屬性。
  5. 存檔後在遊戲裡用 screens.register('shop', { url: 'ui/shop.xml' }) 或 UIPlugin.create({ scene: 'ui/shop.xml' }) 載入。

這本手冊的 XML 範例和 UI 編輯器用同一套排版與繪製程式，在手冊裡試好的 XML 可以直接貼到編輯器的原始碼視窗。

和 3D 場景編輯器一起用

3D 場景編輯器可以把場景搭配的介面檔疊在 3D 畫面上（UI 層），方便對照介面和場景的位置，見3D 場景編輯器的「UI 層」。

  • 在 3D 場景編輯器按「編輯 UI ↗」（或屬性面板裡介面檔的「編輯」），會在另一個分頁用 UI 編輯器打開那個介面檔（網址的 ?file=）。
  • 在 UI 編輯器的每個修改都會即時顯示在 3D 場景編輯器的 UI 層，不用先存檔；存檔或還原後，3D 場景編輯器改回讀磁碟上的檔案。用到同一個介面檔的 3D 介面面板（UIPanel3D）也會跟著更新。
  • 兩個編輯器要開在同一個瀏覽器（用 BroadcastChannel 傳送）。並排兩個視窗最方便；3D 場景編輯器在背景分頁時，瀏覽器會暫停它的畫面，切回去就會更新。

打包時的介面檔

開發時介面檔直接從 public/ui 讀取；node hero build 打包時會把 XML 轉成 JS 模組（tools/ui-xml-bundle.ts），載入方式不變，遊戲程式不用修改。
