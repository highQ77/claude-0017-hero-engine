Hero Engine 是什麼

Hero Engine 是建立在 three.js 上的網頁遊戲引擎：用「實體＋元件」組合遊戲物件，用外掛加上繪製、物理、音效、介面等功能，2D 介面則用 XML 描述、由 Yoga 排版引擎自動排版。

這本手冊怎麼讀

每一章都有可以直接修改的範例。程式碼有語法高亮，點進去就能編輯：

  • TypeScript 範例：按 ▶ 執行（或在編輯器裡按 Ctrl／⌘ + Enter），結果會顯示在下方的預覽框；console.log 的輸出與錯誤訊息顯示在預覽框底下。
  • 3D 畫面可以用滑鼠轉動：在預覽框裡拖曳轉動攝影機、右鍵（或 Shift + 拖曳）平移；先點一下畫面，滾輪才會縮放（捲動手冊時不會誤觸）。手機上用單指轉動、雙指縮放。
  • XML 介面範例：邊打邊更新，不用按執行。按鈕的 onClick 等事件會印在下方，可以切換「手機／平板／全寬」看看 RWD 排版。
  • 改壞了按 還原 回到原本的範例；複製 把程式碼貼到自己的專案。

先試試看：把下面的 text 改成你的名字，或把 background 換成別的顏色。

編輯器的快速鍵：Tab／Shift + Tab 縮排、⌘ + Z 復原、Esc 離開編輯器。搜尋手冊按 /。

引擎的組成

引擎核心很小，只負責主迴圈與外掛管理；其餘功能都是可以選擇安裝的外掛：

模組引用用途
核心@engine/core引擎生命週期、主迴圈、時間
數學@engine/math向量、四元數、顏色（three.js 的數學類別）
實體與元件@engine/ecsWorld、元件、查詢、系統
場景@engine/scene位置旋轉縮放（Transform）、父子關係、場景切換、場景檔（XML／JSON）
繪製@engine/render攝影機、燈光、網格、點選物件
輸入@engine/input鍵盤、滑鼠、觸控、手把、動作對應
腳本@engine/scripts用類別寫物件的行為（類似 Unity 的 MonoBehaviour）
動畫@engine/animation補間動畫、時間軸、模型動畫與狀態機
物理@engine/physics剛體、碰撞體、射線（Rapier）
粒子@engine/particles火焰、煙霧、火花、爆炸
音效@engine/audio音效、背景音樂、3D 空間音效
資源@engine/assets載入模型、貼圖、音效、字型
2D 介面@engine/ui2dXML 介面、Yoga 排版、30 多種元件
更多@engine/text3d、postfx、shaders、ai、network、ui3d、plugins3D 文字、後製效果、著色器、AI、多人連線、3D 介面、套件

開發時另外有四個網頁編輯器（node hero dev 時提供，不會打包到遊戲裡）：3D 場景編輯器（/s3d-editor，編輯場景檔與預製物件）、UI 編輯器（/ui-editor，編輯介面檔，和 3D 場景編輯器可以即時連動）、著色器編輯器（/shader-editor）與音效編輯器（/se-editor）。另外 /portal 是入口頁，列出所有專案，點一下就能切換；/doc 是這本使用手冊。完整網址見開始使用的「開發網址」。
